## 🔒 Hacking Study Repository

개인 보안 연구 및 해킹 공부 내용을 정리하는 레포지토리입니다.  
Burp Suite를 이용한 실습과 보안 취약점 분석, 모의해킹 준비 과정을 기록합니다.

---

## 📋 학습 목표

- 웹 보안 취약점 심층 이해 및 실습
- OWASP Top 10 마스터
- 실무 해킹 도구(Burp Suite) 능숙도 향상
- 모의해킹 및 보안 인턴십 준비

---

## 📁 디렉토리 구조

```
├── web-vulnerabilities/          # 웹 취약점 분류
│   ├── web-cache-deception/      # WCD (Web Cache Deception)
│   ├── server-side-vulns/        # 서버사이드 취약점
│   └── owasp-top-10/             # OWASP Top 10
│
├── burp-suite-labs/              # Burp Suite 실습 기록
│   ├── portswigger-labs/         # PortSwigger Lab 풀이
│   └── writeups/                 # 상세 분석 및 풀이
│
├── case-studies/                 # 실제 해킹 사례 분석
│   └── recent-hacking-cases/     # 최근 해킹 사례 모음
│
├── interview-prep/               # 모의해킹 면접 준비
│   ├── technical-questions/      # 기술 면접 질문
│   └── practical-scenarios/      # 실전 시나리오
│
└── daily-notes/                  # 매일 공부 기록
    └── [YYYY-MM-DD].md           # 날짜별 학습 노트
```
